# LAB4

## Tasks done in this lab
- Loaded the Amazon unlocked phones reviews and made a sentiment column from the rating
- 5 preprocessing steps (lowercase, links/html, numbers and punctuation, stopwords, stemming)
- Train / test split
- TF-IDF features
- Trained a Naive Bayes classifier
- Checked accuracy, the classification report and the confusion matrix

DisneylandReviews.csv (used in the lab example) is in this folder.
The Amazon phones file (Amazon_Unlocked_Mobile.csv) is too big for GitHub (over 100 MB). The notebook downloads it from Kaggle: `PromptCloudHQ/amazon-reviews-unlocked-mobile-phones`.
